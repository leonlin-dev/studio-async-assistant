# studio-async-assistant

异步 AI 助手：让每个用户只关心他想关心的内容，助手负责其余内容，并完成用户期待的交付物的产出。

## 状态

调研、设计阶段。目标是在动手实现之前，推敲并确定原理性方案（principled design）。

## 文档结构

- `docs/00-vision.md` — 项目愿景与问题定义
- `docs/01-principles.md` — 原理性方案的推敲稿（开放问题、候选原理、裁决记录）
- `docs/decisions/` — 逐项设计裁决（一人一议，可推翻，留痕）

## 约定

- 设计阶段一切以文档为准；结论必须落盘，讨论必须收敛为可裁决的问题。
