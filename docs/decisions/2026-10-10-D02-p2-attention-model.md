# D02 · P2 关注模型：三层结构 + 免打扰预算

状态：**建议裁决（proposed）— 2026-10-10，待用户否决/批准**

## 裁决内容

### D02-a 预算只约束"直接打扰"
免打扰预算是硬上限，约束对象是**直接打断用户的行为**（ask 出口 + 高优推送）。用户显式订阅的主题不占预算，但聚合呈现防止刷屏。预算耗尽时，ask 自动降级为 park + 合入摘要。

### D02-b 推断关注 digest-first
助手推断的"值得关注项"永不直接打断，只进入摘要；用户点开/确认后才升级为显式关注。用户对推断的每次纠正（含忽略）都作为负信号写回记忆。

### D02-c 关注粒度 = 主题
关注单位是主题（topic），任务、交付物、消息挂在主题下。主题可自动拆分/合并，操作留痕。

## 理由

预算把"打扰"变成稀缺资源，是逼助手学会合并与摘要的机制化手段；digest-first 让推断关注零成本试错——猜错不打扰，猜对被升级。"只关心想关心的"由此成为机制而非口号：显式订阅保证不漏，预算+摘要保证不淹。
