# D03 · P1 任务一等公民 + OQ1 自查任务准入

状态：**建议裁决（proposed）— 2026-10-10，待用户否决/批准**

## 裁决内容

### D03-a 统一表示 + 分级仪式
一切工作统一为任务（同一生命周期 `draft → active → blocked → delivered → accepted/closed`），但**仪式按规模分级**：
- **微任务**：单步、即时，免契约，批量呈现于摘要；
- **标准任务**：契约前置（D05）；
- **战役**：多任务组合，共享一个交付物目标。

统一表示使统一排序/升级/交付成为可能；分级仪式消解"探索性工作被管理开销压死"的反方。

### D03-b OQ1 自查任务三重准入门槛
助手自查发现的问题转化为任务，必须同时满足：
1. 契约草稿已拟（含探索型契约）；
2. 价值预估已写明（为什么值得做、期待什么交付物）；
3. 并发自查任务数在信任度允许的上限内。

用户可随时看到并关闭任何自查任务；**用户关闭自查任务不追责信任度**（用户有最终裁量权，且这不代表助手做错了）。

## 理由

OQ1 的本质是"代理的主动性边界"。三重门槛保证自查任务与用户任务走同一套可审计流程；关闭不追责则保住了"用户只关心想关心的"——用户不必为纠正助手的主动性付出心理成本。
