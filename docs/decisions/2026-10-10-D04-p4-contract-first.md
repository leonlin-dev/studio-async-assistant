# D04 · P4 交付物契约前置

状态：**建议裁决（proposed）— 2026-10-10，待用户否决/批准**

## 裁决内容

### D04-a 验收标准三级判定
1. 可机检的（测试、gate、字节对比）→ 机检；
2. 不可机检的 → LLM 裁判 + 裁决理由留痕；
3. 用户发起任务的交付物 → **最终必须用户验收**（机检/LLM 裁判只是预检，省的是用户时间，不是用户裁决权）。

### D04-b 探索型契约最低内容
问题陈述 + 完成判据（"该问题被回答"）+ 边界（明确不做什么）。三要素缺一不许开工。

### D04-c 契约确认人
- 用户发起：用户一句话确认即生效；用户使用默认模板未表态时按模板生效。
- 自查发起：助手自拟自批 + 留痕，用户事后可否决；否决触发信任降级。

## 理由

"完成用户期待的交付物"中，"期待"必须外化为机器可判定的契约，否则异步执行无法自检，只能最后靠用户验收，异步退化为同步。D04-a 的三级判定同时保住两件事：用户裁决权不被架空（第 3 条），用户时间不被浪费（第 1、2 条做预检）。
