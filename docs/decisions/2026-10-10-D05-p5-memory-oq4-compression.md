# D05 · P5 记忆组织 + OQ4 上下文压缩

状态：**建议裁决（proposed）— 2026-10-10，待用户否决/批准**

## 裁决内容

### D05-a 记忆主索引 = 用户关注主题
记忆按"每个用户关心什么"组织，不按任务历史组织。任务结束即归档；只有进入关注模型的事实（偏好、纠正、领域知识、在跟踪的事）被提升为长期记忆，并挂到主题（D02-c）下。

### D05-b OQ4 压缩红线
- **永不压缩、逐字保留**：决策留痕（问/赌/搁记录）、契约、验收结果。
- **可摘要**：过程上下文（中间输出、探索细节）。
- 恢复界面固定为"一页状态"：主题现状 + 待决事项 + 下一步。用户回来时的第一个问题（"我关心的事怎么样了"）由这一页直接回答。

## 理由

决策留痕是信任度调整（P6）和事后审计的唯一凭据，压缩它等于销毁证据链；过程上下文不压缩则会撑爆任何存储与注意力预算。红线划在"证据 vs 过程"上，而不是划在时间或大小上。
